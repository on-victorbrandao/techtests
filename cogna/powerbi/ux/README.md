# Design system e tema Power BI — Cogna Educação

Esta pasta reúne os arquivos visuais, protótipos de referência e o arquivo de tema oficial para o Power BI.

## Arquivos disponíveis

1. **`cogna_theme.json`**: Arquivo de tema oficial do Power BI (JSON). Configura as cores corporativas da Cogna (`#5219A1`, `#FFAD01`, `#7433DA`, `#0095FF`, `#0BB783`), fontes (`Poppins` e `Roboto`), plano de fundo (`#FAFBFC`), cartões brancos com cantos arredondados (`16px`) e sombras suaves.
2. **`opcao1-exemple-prototype-dashboard-cogna.png`**: Protótipo de referência visual (layout estilo SaaS executivo com barra lateral, header superior e grade de cards analíticos).
3. **`opcao1-exemple-prototype-dashboard-cogna.svg`**: Vetor SVG original do protótipo com coordenadas e componentes.
4. **`opcao2-exemple-prototype-dashboard-cogna.svg`**: Segunda opção de referência visual.

## Cores principais

- Roxo Cogna (Primária): `#5219A1`
- Roxo Elétrico (Destaque): `#7433DA`
- Ouro / Âmbar (Secundária): `#FFAD01`
- Azul Omnichannel: `#0095FF`
- Verde Sucesso: `#0BB783`
- Vermelho Alerta: `#EF4444`
- Fundo do Canvas: `#FAFBFC`
- Fundo dos Cards: `#FFFFFF`
- Texto Principal: `#151D48`
- Texto Secundário: `#737791`

## Instruções para importar no Power BI Desktop

1. Abra o arquivo `.pbix` no Power BI Desktop.
2. Vá na guia **Exibição** > **Temas** > **Procurar temas**.
3. Selecione `cogna_theme.json` nesta pasta.
